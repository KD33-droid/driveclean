# DriveClean

**Open-source Android Privacy & Driving Companion**

DriveClean is a privacy-focused Android application designed to help users understand their device's application ecosystem, identify unnecessary permissions and privacy risks, and create a cleaner, distraction-free driving experience.

## Objectives

- Audit installed Android applications.
- Identify sensitive permissions and privacy risks.
- Provide transparent application classifications.
- Offer safe and reversible optimization recommendations.
- Provide a customizable driving Focus Mode.
- Monitor available battery and application usage information.
- Support multiple Android manufacturers.
- Provide English, Telugu, Hindi, Tamil and Kannada interfaces.

## Principles

- Android-wide compatibility.
- Local-first architecture.
- No root requirement.
- No mandatory cloud account.
- User consent for every device modification.
- Transparent audit findings.
- Reversible operations wherever technically possible.

## Technology

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK
- Room
- DataStore
